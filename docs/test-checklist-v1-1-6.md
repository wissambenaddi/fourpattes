# Visual QA checklist

- [ ] 375 px: logo remains sharp; hero buttons fit on one row or wrap cleanly.
- [ ] 448 px: dog and cat remain visible; no horizontal seam.
- [ ] 768 px: central text remains readable and animals are balanced.
- [ ] 1024 px: hero does not stretch; navigation remains aligned.
- [ ] 1366 px: composition matches the intended 14-inch layout.
- [ ] 1440 px: artwork fills the intended area without distortion.
- [ ] 1920 px: safe blue gutters blend with the artwork.
- [ ] 2560 px: artwork stays at native maximum width and remains centered.
- [ ] Product names, prices and badges remain readable.
- [ ] No horizontal overflow on any tested viewport.
